# example — サンプル機械

このアプリの「読込」ボタンで開ける機械(DFA / DTM)のサンプルです。いずれも
`{ v, kind, label, input, spec }` エンベロープの JSON で、`spec` は契約
(`docs/contract.md`)に従います。読み込んだら「再生」で実行できます。

## dfa-divisible-by-3.json — DFA(正則言語の例)
2進数(MSB 先頭)が **3 の倍数**かを判定する DFA。状態 `r0/r1/r2` が「これまで
読んだ値 mod 3」を表し、ビット `d` を読むごとに `r ← (2r + d) mod 3`。受理は
`r0`(余り 0)。有限状態だけで剰余を数えられる、DFA=正則言語の綺麗な例です。
- 入力アルファベット: `{0, 1}`
- サンプル入力: `110`(=6 → 3 の倍数 → **受理**)。`10`(=2)なら拒否。

## dtm-palindrome.json — DTM(DFA にはできない例)
`{a, b}` 上の **回文(palindrome)** を判定する 1 テープ DTM。両端の記号を突き
合わせながら内側へ縮めます。左端の未照合を `x`、右端の未照合を `y` でマークし、
「左端の未照合を x にする → 右端まで走って一致を確認し y にする → 左の x まで
戻る」を繰り返します。左右が出会う(全照合)か中央 1 文字だけ残れば受理、途中で
不一致なら拒否。回文言語は**非正則**なので DFA では判定できず、テープ(記憶)を
持つ TM ならではの例です。
- 入力アルファベット: `{a, b}`、作業記号: `x, y`(空白は null)
- サンプル入力: `abba`(**受理**)。`ab` なら拒否。「再生」で最後まで走らせてください。
- 実装メモ: このエンジンのテープは**左端が境界**(開始位置より左へは動けない)なので、
  記号を消さずマーカで進め、左端を越えて左移動しない設計にしています。

## accdfa.json — DTM(ユニバーサル DFA シミュレータ)
**DFA の符号化と入力語をテープに載せると、その DFA が語を受理するかを判定する**
DTM。DFA は "データ"、ACCDFA 自体は固定の 1 台で、**任意個の状態**の DFA を扱え
ます(状態は 2 進固定幅で符号化。入力アルファベットは `{a, b}` 固定)。
75 状態 / 884 遷移。判定言語は A_DFA = { ⟨D, w⟩ | DFA D が w を受理 }。

### テープ符号化
```
{ t ;E1;E2;…;En f ;A1;…;Am s C i w }
```
- キーは 1 文字トークン: `t`=遷移表, `f`=受理状態, `s`=現在状態(開始状態で初期化・
  実行中に更新), `i`=入力語
- `E` = `<from の2進><記号 a|b><to の2進>`(状態は幅 W の2進。記号 a/b が from と to
  を分ける)
- `A` = 受理状態(2進、`;` 区切り) / `C` = 現在状態(2進) / `w` = 入力語(a/b)
- 状態は `0,1,2,…` を **W = ⌈log₂(状態数)⌉** ビットの2進で表す

サンプル入力(同梱)は「a が偶数個」の DFA を `aa` で判定するテープ
`{t;0a1;0b0;1a0;1b1f;0s0iaa}` → **受理**。

### accdfa_encode.py — DFA JSON をテープ文字列へ変換
このアプリで保存した DFA の JSON(状態名は任意文字列で可)を ACCDFA 用テープに
変換します:
```
python3 example/accdfa_encode.py 保存したdfa.json [入力語]
```
出力されたテープ文字列を、`accdfa.json` を読み込んだ後の「入力(テープ)」欄に貼り、
「再生」で実行してください(入力アルファベットは `{a, b}` のみ対応)。

> 補足: ACCDFA は 2 進のビット比較で 1 ステップが細かく、総ステップ数が多くなります
> (幅 W が大きい・語が長いほど顕著)。「進む」連打より「再生(速度 4x)」が快適です。
